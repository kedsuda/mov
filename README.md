# เที่ยวพอดีงบ 🧭

เว็บวางแผนเที่ยวไทยตามงบประมาณ ใช้งานง่าย รองรับมือถือ

กรอก **จังหวัด · งบประมาณรวม · จำนวนวัน · จำนวนคน · สไตล์การเที่ยว** แล้วรับแผนเที่ยวรายวัน พร้อมแผนที่และค่าใช้จ่ายแยกหมวด

🔗 https://kedsuda.github.io/mov/

## ฟีเจอร์

- **หน้ากรอกข้อมูล** — เลือก 12 จังหวัดยอดนิยม งบ (มีปุ่มลัด) วัน/คน สไตล์ (ธรรมชาติ คาเฟ่ ทะเล ประวัติศาสตร์ ตลาด/ของกิน ช้อปปิ้ง) และเลือกรวมค่าเดินทางจากกรุงเทพฯ ได้ — แสดงทันทีว่างบนี้ได้ทริประดับไหน
- **หน้าผลลัพธ์**
  - แผนรายวันแบบไทม์ไลน์: เวลา สถานที่ เวลาเดินทางและระยะทางโดยประมาณ มื้ออาหาร ที่พัก
  - สรุปค่าใช้จ่าย 4 หมวด: ที่พัก · อาหาร · ค่าเดินทาง · ค่าเข้าชม พร้อม **ยอดรวม** และ **เงินคงเหลือ/เกินงบ** (แถบล่างค้างไว้บนมือถือ)
  - **แผนที่** (Leaflet + OpenStreetMap): หมุดลำดับสถานที่แยกสีตามวัน ที่พัก เส้นทางโดยประมาณ เวลาเดินทางแต่ละช่วง และ **สถานที่ใกล้เคียง** ที่กดเพิ่มลงแผนได้
  - แก้ไข ลบ (มีเลิกทำ) ย้ายวัน เพิ่มสถานที่แนะนำ หรือเพิ่มรายการเอง — ยอดรวมคำนวณใหม่ทันที
- **บันทึกแผน** ไว้ในเบราว์เซอร์ (localStorage) กลับมาดู/แก้ไขภายหลังได้ที่ “แผนของฉัน” — แผนที่บันทึกแล้วจะบันทึกอัตโนมัติเมื่อแก้ไข
- **วันเดินทาง** — เลือกวันที่ออกเดินทาง แผนแสดงวันที่ของแต่ละวัน และเตือนถ้าสถานที่อาจไม่เปิดในวันนั้น (เช่น ถนนคนเดินวันอาทิตย์)
- **ภาพรวมงบก่อนสร้างแผน** — แถบสัดส่วนที่พัก อาหาร เดินทาง กิจกรรม และเงินคงเหลือ
- **เพิ่มสถานที่เอง** — ค้นหาชื่อ (OpenStreetMap Nominatim) หรือแตะแผนที่เพื่อปักหมุด
- **วิธีเดินทางในพื้นที่** — ตามงบ (อัตโนมัติ) / รถสาธารณะ (คิดต่อคน เผื่อเวลารอรถ) / ขับรถเอง (ค่าน้ำมันตามระยะทางจริงของแต่ละวัน + ค่าจอด; ไป-กลับกรุงเทพฯ คิดค่าน้ำมัน ไม่รวมทางด่วน) / เช่ารถขับเอง — ค่าตั้งต้นอยู่ใน `TRAVEL` (`assets/js/data.js`)
- **ข้อจำกัดของผู้ร่วมทริป** — มีเด็กเล็ก ผู้สูงอายุ ใช้รถเข็น งดเดินเยอะ: เลี่ยงสถานที่ที่ทางชัน เดินป่า ลุยน้ำขึ้นเรือ (ตาราง `ACCESS` ประเมินจากข้อมูลทั่วไป ไม่ใช่ข้อมูลตรวจสอบหน้างาน) และลดชั่วโมงเที่ยวต่อวัน · จำกัดงบอาหารต่อมื้อได้
- **สำรองและย้ายแผน** — ส่งออกแผนทั้งหมด (หรือทีละแผนจากเมนูแชร์) เป็นไฟล์ `.json` แล้วนำเข้าในเครื่องอื่น ไฟล์ถูกตรวจทุกช่องเหมือนลิงก์แชร์ แผนที่มีอยู่แล้วจะถูกแทนที่เมื่อไฟล์ใหม่กว่าเท่านั้น
- **ใช้งานออฟไลน์** — service worker (`sw.js`) เก็บไฟล์เว็บ ภาพจังหวัด และไทล์แผนที่ที่เคยเปิดดู (สูงสุด 800 ไทล์) แผนที่บันทึกไว้เปิดได้แม้ไม่มีเน็ต
- **การเข้าถึง** — ปุ่ม “ข้ามไปที่เนื้อหาหลัก” · Tab วนอยู่ในหน้าต่างที่เปิดอยู่ · Esc ปิดหน้าต่าง · สีตัวหนังสือผ่านคอนทราสต์ WCAG AA (4.5:1)
- **แชร์/พิมพ์** — ลิงก์แชร์เก็บข้อมูลแผนทั้งหมดไว้ในลิงก์ (บีบอัด ไม่ต้องมีเซิร์ฟเวอร์) คัดลอกสรุปเป็นข้อความ หรือพิมพ์/บันทึกเป็น PDF

## ภาพจังหวัด

ภาพจาก Wikimedia Commons (CC BY / CC BY-SA) ดาวน์โหลดและปรับขนาดด้วย `node scripts/fetch-images.mjs`
เครดิตผู้ถ่ายและสัญญาอนุญาตอยู่ใน `assets/js/credits.js` และแสดงบนเว็บที่ปุ่ม “เครดิตภาพ”

## ข้อมูลและความแม่นยำ

ข้อมูลทั้งหมดใน `assets/js/data.js` เป็น **ข้อมูลตัวอย่างและค่าประมาณ** ไม่ใช่ข้อมูลสด:

- ราคาที่พัก อาหาร ค่าเดินทาง และค่าเข้าชม — ค่าประมาณสำหรับคนไทย
- พิกัดสถานที่ — ตำแหน่งโดยประมาณ (ปุ่ม “เปิดใน Google Maps” ใช้ค้นหาตำแหน่งจริง)
- เวลาเดินทาง — คำนวณจากระยะเส้นตรง × 1.35 และความเร็วเฉลี่ยตามระยะทาง ไม่ได้ใช้ API แผนที่

หน้าเว็บแจ้งผู้ใช้ทุกจุดว่าเป็นค่าประมาณ และให้ตรวจสอบก่อนเดินทาง

## วิธีจัดแผน (`assets/js/planner.js`)

1. คำนวณค่าที่พัก (ห้องละ 2 คน) อาหาร และค่าเดินทางของแต่ละระดับ (ประหยัด/มาตรฐาน/สบาย)
2. เลือกระดับสูงสุดที่ไม่เกิน 90% ของงบ **และไม่ต้องตัดสถานที่ท่องเที่ยว** (เก็บ 10% เป็นเงินสำรอง)
3. เลือกสถานที่ตามสไตล์ก่อน จัดกลุ่มรายวันตามระยะทาง เติมช่วงบ่ายที่ว่าง ค่าเข้าชมรวมไม่เกินงบที่เหลือ
4. วันที่มีทริปเต็มวัน (เช่น ดอยอินทนนท์ ทัวร์เกาะ) ออกเช้าและไม่จัดสถานที่ช่วงเย็นเพิ่ม

## พัฒนาและทดสอบ

ต้องมี Node.js 20+ (ไม่มี dependency ภายนอก)

```bash
npm run dev         # build แล้วเปิด http://localhost:8080
npm run test:unit   # ทดสอบเครื่องมือจัดแผน 1,440 กรณี
npm test            # unit + E2E ด้วย Edge/Chrome headless
```

## Deploy

push ไป `main` → GitHub Actions รัน unit tests, build และเผยแพร่ไป GitHub Pages อัตโนมัติ (`.github/workflows/deploy.yml`)

## โครงสร้าง

```
index.html               หน้าเว็บ (หน้าหลัก / แผนของฉัน / ผลลัพธ์ ด้วย hash routing)
assets/css/style.css     ดีไซน์
assets/js/data.js        ข้อมูลตัวอย่าง: จังหวัด โซน สถานที่ พิกัด ราคา
assets/js/planner.js     เครื่องมือจัดแผน (ไม่ยุ่งกับ DOM)
assets/js/app.js         หน้าจอ แผนที่ การแก้ไข และการบันทึก
scripts/                 build และเซิร์ฟเวอร์ทดสอบ
tests/                   unit tests และ E2E tests
```
